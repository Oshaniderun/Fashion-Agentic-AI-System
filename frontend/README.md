# FASHORA Frontend — Agent 1

React + TypeScript + Vite UI for the Style & Wardrobe Intelligence Agent.

## Run

```bash
npm install
npm run dev
```

Requires the Agent 1 backend on http://localhost:8001 (Vite proxies `/api` and `/uploads`).

## Pages

- Dashboard
- Fashion Request
- Wardrobe / Add Clothing / Item Detail
- Analysis Result
- Agent Status
- Security Lab
- Settings
- Login / Register
